## 校准记录

- 最小字号 = (视距 / 200) × (1080 / 屏高) = (6000 / 200) × (1080 / 2250) = **14.4px** → 取 **14px**。
- 14px 等于 `--dvk-screen-font-size-xs`，因此**不需要整组字号上调**；彩色字符（状态色）按 ≥ 21 弧分复核，14px 在 6m 视距下满足。
- 屏幕是拼接大屏但**单屏输出 1920×1080**，不做多屏拼接缝补偿（本案例不涉及跨屏元素）。

## 约束

- 颜色只有一个来源：`--dvk-color-*`（`cyber-blue` 主题包）；不引入第二套颜色源。
- 屏幕令牌 `--dvk-screen-*` 作用域 `.dvk-screen`，不进主题。
- 一屏一套主题；强调区域用 `--dvk-color-accent`，不用第二套主题。
