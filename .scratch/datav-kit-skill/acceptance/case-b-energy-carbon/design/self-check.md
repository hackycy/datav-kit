## 0. 硬编码值检查（必须先跑）

对 `index.html` 的 `<style>` 做 px 字面量扫描，逐个判定「令牌引用」还是「模式值 / 场景值 / 画布常量」。

```
px literals found: 13
```

| 字面量 | 判定 | 依据 |
| --- | --- | --- |
| `1920px` / `1080px` | 画布常量 | P1 设计画布，锁定值 |
| `4px solid` ×2（P2 左右信息块） | 模式值 | P2 参数：4px 强调左边框 |
| `5px 9px`（P8 状态片） | 模式值 | P8 参数：chip padding 5px 9px |
| `8px`（P9/P10 进度槽） | 模式值 | P9 参数：track height 8px |
| `150px`（P10 名称列） | 已登记偏离 D1 | 120px 会截断楼宇名 |
| `16px / 8px / 12px / 4px / 10px`（演示态控件） | 画布外 | `.demo-controls` 在 1920×1080 画布之外 |
| `44px` 出现在注释中 | 非声明 | 注释文字，非 CSS 值 |

结论：**0 处未登记硬编码值**。所有屏幕尺寸要么是 `--dvk-screen-*` 令牌引用（51 处），要么是上面逐条列出的模式值 / 场景值 / 画布常量；所有颜色都来自 `--dvk-color-*`（16 处引用），无颜色字面量。
