# 是否附带参考大屏示例

Status: resolved
Type: grilling
Blocked by: —

## Question

是否随 skill 附带一套完整"参考大屏"作为端到端示例？

（雾区到期项，上游 08、12 已结票未回答。）

## Answer

**不附带完整大屏，但给一个"最小可运行示例"**：`assets/minimal-example.html` —— 一个屏 + 2–3 个面板 + 1 个图表，可直接双击打开。

理由：完整大屏等于第五套模板 + 长期维护（发版 checklist 还要多一项）；最小示例已经足够让人 5 分钟看到效果。

**约束归属**：文件进 12 的目录树；`README.md` 里给出入口。
