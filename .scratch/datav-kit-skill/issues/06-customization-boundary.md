# 深度定制的边界与表达方式

Status: resolved
Type: grilling
Blocked by: —

## Question

大屏内容差异大，规范必须允许深度定制，但"定制"和"不稳定"只有一线之隔。要定：

1. 定制的表达方式是什么？（令牌覆盖 / 布局插槽 / 显式偏离登记 / 自由 CSS + 清单）
2. 哪些是"可以改"的？（间距、密度、区块比例、装饰强度、主题……）
3. 哪些是"改了就不稳定"的红线？（安全边距、对比度下限、动效上限、内容安全区、信息层级……）
4. 偏离规范时 agent 必须做什么？（声明？降级？换方案？）
5. 定制到什么粒度就必须**回到原型重来**，而不是局部改。


## Answer

定制的三层结构、载体、红线、权限档位、声明机制与回原型触发条件如下。**术语以地图的术语表为准。**

### 1. 定制的三层（在哪开定制面）

| 层 | 管什么 | 作用域 |
| --- | --- | --- |
| **主题层** | 色系（`--dvk-*`） | 一套项目专属主题 CSS |
| **项目层** | 间距刻度、密度、字阶、动效预算、骨架选型 | 每套大屏一份 |
| **区块层** | 单个面板 / 某一栏的变体（面板头形态、数据展示模式、图表类型） | 局部 |

### 2. 载体：哪些是一等公民

- **令牌覆盖**（CSS 变量作用域）与**区块替换**是**一等公民**——skill 必须主动引导走这两条。
- **组件属性**属常规用法，不占"定制"名额。
- **自由 CSS 允许，但必须登记**：它是深度定制的逃生舱，关掉会被绕过，敞开无约束会失稳——所以"开着，但看得见"。

### 3. 红线（四类，具体条目由「设计规范条目与评分表派生规则」填）

1. **可读性**：对比度下限（正文 ≥4.5:1、大字 ≥3:1、非文字 ≥3:1）、最小字号、关键数据不依赖 hover。
2. **几何**：等比缩放（禁止非等比拉伸）、内容安全区语义、安全边距。
3. **语义**：每个光效 / 动效 / 装饰必须有具名的数据或交互映射（"只'好看'就删掉"）。
4. **无障碍**：`prefers-reduced-motion` 必须生效、键盘可达。

### 4. 权限三档与偏离清单的收口

- **硬红线**：不可碰。
- **建议值**：设计规范里的具体数值与形态（间距刻度、字号、密度、动效时长、装饰预算、安全边距取值、面板头形态……）——**偏离必须登记**。
- **自由区**：业务内容、数据驱动的结构与文案、图表具体 option——**不用登记**。
- **自由 CSS 归"建议值"档**：改到建议值就登记，纯业务排版则落自由区。

**偏离清单**：项目内一份显式文件（如 `DESIGN.md` 的 Deviations 节），**每条附一句"规范在此为什么不适用"**；评审时逐条核对，**未声明的偏离直接算缺陷**。

### 5. 回原型的触发条件

| 改什么 | 怎么走 |
| --- | --- |
| 令牌 / 主题 | 就地改 |
| 单个区块内的数据展示模式、密度 | 就地改 + 登记偏离 |
| **骨架**（栏数、行高比例、顶栏形态、区块增删） | **必须回原型重选** |
| 任何触碰**红线**的诉求 | **必须回原型**（换方案，不是改参数） |

理由：原型是**视觉契约**，骨架一变契约失效；就地改骨架等于悄悄改契约，这正是返工的来源。

### 6. 自定义主题是顶层入口

skill 必须教 agent 生成项目专属主题（第 6 套 `.dvk-theme-<name>` CSS）。约束两条：**只声明 `--dvk-*` 变量**（不得引入第二套颜色源）、**必须过对比度红线**。生成与校验流程另开票（见「项目专属主题的生成与校验」）。
