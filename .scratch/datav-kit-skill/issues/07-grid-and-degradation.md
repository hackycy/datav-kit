# 栅格基准与降级策略

Status: resolved
Type: grilling
Blocked by: —

## Question

1. 固定设计画布：**1920×1080 还是 1920×1280**？（Demo 用的是后者）为什么？
2. `dvk-fit-screen` 的参数：mode（contain / cover）、align，以及非 16:9 视口下的留白处理。
3. 栅格：列数与沟槽（12 / 24 列？是否 8pt 对齐？），安全边距取值。
4. 降级策略：超宽屏（21:9、拼接屏）、竖屏、小屏（1440 笔记本）分别怎么处理——缩放、重排，还是给出明确的"不支持"边界。
5. 以上哪些写进设计规范作为硬规则。

**已知坑 1（03 发现）**：ScenicSpotCommandScreen 用固定 px 行高，在 1080 画布上总高溢出 26px 被 `overflow:hidden` 裁掉；Aviation 的流式 `minmax(0,1fr)` 才正确。栅格基准必须明确"行高流式 vs 固定"的规则。

**已知坑 2（01 查证）**：`dvk-fit-screen` 用**布局之后**的 `transform: scale()`，因此 `contain` 且视口小于 1920×1080 时，`--dvk-line-width: 1px` 会被缩成**亚像素**（`fill` 模式则非等比拉伸字形与线宽）。标准解法是 SVG 的 `vector-effect: non-scaling-stroke`。这直接影响"视觉稳定"。
**Canvas 侧同理（02 实测）**：`transform: scale(2)` 下每个视觉像素只剩 0.5 个后备像素，且本仓库 `echarts@6.1.0` 的 `resize()` **不刷新 DPR**——栅格降级策略要把这条算进去。

**事实约束（01 查证）**：**没有任何标准给出安全边距的 px 值**——SMPTE ST 2046-1 只给 93%/90%，EBU R95 与 ITU-R BT.1848 只给 3.5%/5% 内缩；**21:9 超宽完全没有标准**。所以安全边距必须自定并标注为自定义。


## Answer

### 1. 画布与缩放

- **设计画布**：1920 × 1080（16:9）。`dvk-fit-screen` 的默认值即 1920×1080。
- **`mode="contain"` + `align="center center"`**。不用 `cover`（裁切，撞 04 的 1.3 红线）、不用 `fill`（非等比拉伸，撞 1.1）、不用 `scroll`（大屏不滚动）。
- **画布之外的留白用氛围层填充**（背景渐变 / 网格 / 光晕），不做死黑边——留白也是视觉的一部分。

### 2. 缩放副作用（三条，全部要处理）

| 副作用 | 处理 |
| --- | --- |
| 亚像素线宽（`transform: scale()` 是布局后变换） | SVG 侧用 `vector-effect: non-scaling-stroke`（04 条目 1.7）；避免在缩放场景依赖 1px CSS 边框 |
| ECharts 模糊（本仓库 6.1.0 的 `resize()` **不刷新 DPR**） | **图表优先 SVG renderer**（ECharts 官方：SVG 放大不模糊）；Canvas 只留给大数据量 |
| 非整数缩放关闭次像素抗锯齿 | 无法完全避免，作为已知代价记录 |

### 3. 栅格系统

- **12 列 / 沟槽 24px / 外边距 48px**，8pt 对齐。1920 下每列宽 = (1920 − 96 − 11×24) / 12 = **130px**。
- **安全边距**：默认 **48px**（8pt 刻度，≈2.5%）；**拼接屏或有过扫描风险的场景按 EBU R95 graphics safe 内缩 5%**（96px 水平 / 54px 垂直）。
- **间距落地值**（均在 8pt 刻度上，全部为**建议值**）：

| 项 | 值 |
| --- | --- |
| 屏幕外边距 | 48 |
| 区块间距（栏 / 行之间） | 24 |
| 面板间距 | 16 |
| 面板内距 | 24 |
| 顶栏高 | 104 |
| KPI 条高 | 104 |
| 主区行高 | `minmax(0,1fr)` 流式 |

### 4. 降级策略

| 场景 | 策略 |
| --- | --- |
| **16:9**（基准） | contain 铺满 |
| **超宽 21:9 / 32:9** | 16:9 内容区居中，两侧做**辅助信息带或氛围层**；**不拉伸、不裁切** |
| **拼接屏** | 按 T/CIDADS **定高 1080，宽 = 拼接单元数 × 1920**；拼缝 0.5–3.5mm；**线宽 <2px 或字号 <16px 的精细元素绕开拼缝** |
| **竖屏** | **明确不支持**——写进 skill 的范围声明，不是规范条目 |
| **小屏 ≤1440（笔记本）** | contain 缩放仅供**开发预览**，不作为交付目标；交付目标始终是设计画布尺寸 |

**21:9 无任何标准可引**（r1 确认），因此只给"不破坏内容"的保守策略。

### 5. 档位归属

07 的产出**全部是建议值**（可偏离需登记）。唯一相关红线是 04 已定的 1.1–1.3（等比缩放 / 内容安全区 / 不裁切溢出）——红线管几何**性质**，不管具体数字。
