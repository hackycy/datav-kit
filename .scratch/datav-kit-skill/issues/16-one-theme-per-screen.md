# 一屏一套主题

Status: resolved
Type: grilling
Blocked by: —

## Question

同一屏内是否允许混用多个主题类（如左栏 cyber-blue、右栏 solar-gold）？

（雾区到期项，上游 08 已结票未回答。）

## Answer

**不允许——一屏一套主题。**

需要强调某区域就用颜色角色账本里的强调色（`--dvk-color-accent`），不要换主题。

理由：混用等于放弃统一视觉语言，直接违背"稳定美观"；而且 04 条目 4.2（同一色相不得承担互不相关的语义）在混用下几乎必然被违反。

**约束归属**：写进 `references/design-rules.md` 的颜色角色组。
