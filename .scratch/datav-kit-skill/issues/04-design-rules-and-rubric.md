# 设计规范条目与评分表派生规则

Status: resolved
Type: grilling
Blocked by: 01

## Question

新建一套 datav-kit 大屏设计规范（**不沿用现有 Demo 作为基准**）。要定：

1. 规范包含哪些条目、分几组（候选：画布与栅格 / 间距与节奏 / 字体与层级 / 颜色角色 / 装饰预算 / 动效预算 / 数据呈现 / 空态与异常态 / 可访问性）。
2. 每条是**硬规则**（违反即不合格）还是**建议**（可偏离但需声明）。
3. 每条如何**逐条派生**成评审评分表的评分项（评分表结构在 11 定，这里定派生规则与档位）。
4. 哪些条目采用量化阈值（对齐 01 的结论）。

**必须裁决的三个冲突（01 查证）**：

- **动效预算 vs 主题令牌**：主流 UI 动效刻度是 100–500ms（NN/g）、T/CIDADS 给 200–600ms，而本仓库 `--dvk-motion-duration` 是 **2200–2600ms**。规范该以谁为准？装饰动画与交互动效是否分开定预算？（02 已给出一条硬约束：**图表动效不得沿用 `--dvk-motion-duration`**。）
- **装饰预算没有标准**：Material / Carbon / AntD 都没有"单屏装饰元素上限"这一章，只有"每屏主色数"的官方建议（Datawrapper ≤7 / ColorBrewer ≤12 / Carbon 14 / ECharts 9）。装饰预算必须**自定阈值并标注为自定义**。
- **对比度上限**：WCAG 只给下限（正文 ≥4.5:1、大字 ≥3:1、非文字 ≥3:1，且不可四舍五入）；上限只能引工程标准（FAA/NATS ">15:1 可能不适"、MIL-STD-1472H 6:1–10:1、APCA 暗色 Lc −90）。

**产出**：可直接写进 `spec.md` 的规范条目清单。


## Answer

### 0. 结构与分工

规范分 **6 组**，可访问性作为**跨组约束**（组内以 🅰 标注）。本票定"组 + 条目 + 档位 + 阈值来源"；数值由下游填：栅格 → 「栅格基准与降级策略」；令牌 → 「设计令牌集的定义」；图表 → 「ECharts 配置模板规格」；主题色 → 「项目专属主题的生成与校验」。

档位用 06 的三档：**[红线]** 不可偏离 · **[建议值]** 可偏离须登记 · 自由区不评分。

### 1. 画布与栅格

| # | 档位 | 条目 | 阈值 / 判据 | 出处 |
| --- | --- | --- | --- | --- |
| 1.1 | 红线 | 等比缩放 | 禁止非等比拉伸（含文字/线稿的屏不得用 `fill`） | 06 几何类 |
| 1.2 | 红线 | 内容安全区 | 内容必须落在 `contentRect` 内，不得覆盖装饰线稿 | 架构契约 |
| 1.3 | 红线 | **不得内容溢出或裁切** | 任何区块的内容不得被 `overflow` 截断 | 03 发现（Scenic 溢出 26px） |
| 1.4 | 建议值 | 安全边距 | 具体值由 07 定（无标准给 px，须标注自定义） | SMPTE/EBU/ITU 仅给百分比 |
| 1.5 | 建议值 | 栅格列数与沟槽 | 由 07 定 | — |
| 1.6 | 建议值 | 行高流式 | 用 `minmax(0,1fr)`，不用固定 px 行高 | 03 对比 |
| 1.7 | 建议值 | 亚像素线宽 | 缩放场景用 `vector-effect: non-scaling-stroke` | r1 §4.3 |

### 2. 间距与节奏

| # | 档位 | 条目 | 阈值 / 判据 | 出处 |
| --- | --- | --- | --- | --- |
| 2.1 | 建议值 | 间距刻度 | **8pt 网格**：4/8/12/16/24/32/40/48/64/96 | Carbon 8px mini unit；AntD sizeUnit 4 |
| 2.2 | 建议值 | 屏幕内距 / 栏间距 / 面板间距 / 面板内距 | 由 07 定 | — |

### 3. 字体与层级

| # | 档位 | 条目 | 阈值 / 判据 | 出处 |
| --- | --- | --- | --- | --- |
| 3.1 | 红线 🅰 | 最小字号 | 物理高度 = **视距/200**（T/CIDADS）；彩色字符 **≥21 弧分**、推荐 30′（ISO 9241-3 §6.4）；速算 最大视距 = 215 × 字符高 | T/CIDADS / ISO |
| 3.2 | 红线 🅰 | 关键数据不依赖 hover | 主指标必须静态可见 | OpenAI |
| 3.3 | 建议值 | 同屏字体种类 | **≤2 种** | T/CIDADS |
| 3.4 | 建议值 | 字阶数量 | **3–5 种** | Ant Design |
| 3.5 | 建议值 | 字重 | 多数只用 400 / 500，英文加粗用 600 | Ant Design |
| 3.6 | 建议值 🅰 | 行长 | **≤40 CJK 字符**；两端不对齐 | WCAG 1.4.8 |
| 3.7 | 建议值 🅰 | 行高 | **≥1.5×** 字号；段后距 ≥2× | WCAG 1.4.12 |

### 4. 颜色角色

| # | 档位 | 条目 | 阈值 / 判据 | 出处 |
| --- | --- | --- | --- | --- |
| 4.1 | 红线 🅰 | 对比度下限 | 正文 **≥4.5:1**；大字 **≥3:1**（≥18pt / 14pt 粗体 / CJK 等效 ≈24px / 18.5px）；非文字与状态指示 **≥3:1**；**不可四舍五入** | WCAG 2.2 SC 1.4.3 / 1.4.11 |
| 4.2 | 红线 | 颜色角色不重载 | 同一色相不得同时表示多个无关含义 | OpenAI |
| 4.3 | 建议值 | 颜色角色账本 | 10 项：中性背景 / 主焦点 / 次对比 / 有序量级 / 正负变化 / 告警错误 / 选中 / hover-focus / 缺失不确定 / 禁用或过期 | OpenAI |
| 4.4 | 建议值 | 色彩数量 | 数据分类色 **≤5**；界面强调色 **≤2**；语义色另计（**自定义阈值**） | ECharts / Datawrapper / OpenAI |
| 4.5 | 建议值 | 对比度上限 | 正文落在 **7:1–15:1**；暗色避免纯白正文 + 纯黑底（**自定义阈值**） | MIL-STD-1472H 6:1–10:1；FAA/NATS >15:1 不适 |
| 4.6 | 建议值 | 色阶 | 顺序/发散用感知均匀色阶；**禁彩虹色阶** | Moreland 2009 |
| 4.7 | 建议值 | 白色面积 | **≤40%** | T/CIDADS |
| 4.8 | 建议值 | 相邻标记对比 | 当边界本身携带含义时，也要检查相邻数据标记之间的对比 | OpenAI |

### 5. 装饰与动效预算

| # | 档位 | 条目 | 阈值 / 判据 | 出处 |
| --- | --- | --- | --- | --- |
| 5.1 | 红线 | 装饰必须有语义 | 每个光效/动效/装饰必须有一个**具名的数据或交互映射**；只"好看"就删掉 | OpenAI |
| 5.2 | 红线 🅰 | 动效可控 | 自动播放 >5s 须可暂停/停止/隐藏；闪烁 ≤3 次/秒；`prefers-reduced-motion` 生效 | WCAG 2.2.2 / 2.3.1 / 2.3.3 |
| 5.3 | 建议值 | 动效时长（分档） | 交互动效 **150–300ms**；装饰动效**沿用 `--dvk-motion-duration`**（2200–2600ms）；图表动效 **200–400ms** | Carbon/AntD/NN-g；02 实测 |
| 5.4 | 建议值 | 装饰层级 | 每区块 ≤**1 个装饰容器 + 1 条装饰轨**；装饰视觉权重必须低于同区块数据层（**自定义阈值，以层级而非计数定义**） | 本票自定 |
| 5.5 | 建议值 | 反 AI 氛围 | 拒绝：宽笔触、飘带、bokeh/光球、电影感壁纸、单色戏剧、装饰性渐变、无证据的粒子 | OpenAI |
| 5.6 | 建议值 | 渐变与光晕 | 不用渐变代替顺序色板（Carbon）；不用光晕代替阴影表达层级（Material） | Carbon / Material |

### 6. 数据呈现与异常态

| # | 档位 | 条目 | 阈值 / 判据 | 出处 |
| --- | --- | --- | --- | --- |
| 6.1 | 建议值 | 直接标注优先 | 直接标注 > 分离图例；图例须紧贴图表 | OpenAI / Carbon / Datawrapper |
| 6.2 | 建议值 | 图元数量 | 折线 **≤4 条**；饼图分类 **≤5**；仪表指针 **≤3** | ECharts Handbook |
| 6.3 | 建议值 | 图例高度 | **≤30%** 图表高 | Carbon |
| 6.4 | 建议值 | 轴起点 | 柱状图 y 轴从 **0**；折线图不必 | Datawrapper |
| 6.5 | 建议值 | 禁用图形 | 禁 3D 饼/柱；禁双轴；禁彩虹色阶；禁过度平滑 | Wilke / Datawrapper / Moreland |
| 6.6 | 建议值 | **异常态四态** | 无数据 / loading / 加载失败 / 数据陈旧，每态都要有明确呈现 | OpenAI（stale-but-visible） |
| 6.7 | 建议值 | 实时数据 | 优先"陈旧但可见"，带最后更新时间与 live/stale/offline/partial 状态 | OpenAI |

### 7. 可访问性（跨组红线汇总）

4.1 对比度 · 3.1 最小字号 · 3.2 关键数据不依赖 hover · 5.2 动效可控 · **键盘可达 + 焦点外观 ≥2 CSS px 周长且 ≥3:1**（WCAG 2.4.13）· **文字可放大 200% 不丢内容**（WCAG 1.4.4）。

### 8. 评分表派生规则

- **1:1 派生**：每条规范条目 → 一个评分项，标注档位；自由区不评分。
- **红线项 = 二值**（过 / 不过）；**任一项不过 → 该案例不合格**。
- **建议值项 = 三档**（符合 / 有登记偏离 / 未登记偏离）；**未登记即缺陷**。
- **不出总分**——总分会被平均掉，掩盖红线失守。
- **回写规则**：每条"红线失守"或"建议值未达标"必须转成 skill 修订项，否则评审不算完成。
